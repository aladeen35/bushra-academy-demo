# أكاديميات البشرى للغات — خطوات المالك (من الهاتف)

كل الخطوات تعمل من متصفح الهاتف. لا تحتاج حاسوبًا ولا أوامر. **لا ترسل أي كلمة مرور في المحادثة.**

## ١) النشر (بعد دمج الفرع)
1. في GitHub افتح المستودع `bushra-academy-demo` ← **Pull requests** ← ادمج طلب فرع `ccr-a262346d-2ja2bl` في `main`.
2. بعد دقيقة تعمل الأكاديمية الصينية على:
   `https://aladeen35.github.io/bushra-academy-demo/academies/chinese/`
3. تطبيق «البشرى للأدب» لم يُمسّ ويبقى كما هو.

## ٢) النطاق chinese.albushra.app
النطاقات الفرعية تمر عبر موجّه albushra.app (مستودع `test`، المجلد `albushra-app`):
1. افتح المستودع `test` ← ادمج طلب فرع `ccr-a262346d-2ja2bl` في `main`.
2. يُنشر الموجّه تلقائيًا من **Actions ← albushra.app**. بعده:
   - `chinese.albushra.app` يفتح الأكاديمية الصينية.
   - `korean.albushra.app` و`japanese.albushra.app` يعرضان صفحة «قريبًا» حتى نبنيهما.
   - الصفحة الرئيسية `albushra.app` تعرض الأكاديميات الثلاث ضمن قسم التعليم.

## ٣) Firebase: حساب موحّد ومزامنة ومعلّم ذكي (خطة Spark المجانية)
مشروع واحد لكل الأكاديميات (الصينية والكورية واليابانية)، مستقل عن «البشرى للأدب» و«هدايا أمير».
1. افتح `console.firebase.google.com` ← **Add project** ← الاسم `albushra-academies` ← أوقف Google Analytics ← **Create project**.
2. **Build ← Authentication ← Get started**:
   - فعّل **Google** (اختر بريد الدعم) ← **Save**.
   - فعّل **Email/Password** ← **Save**.
   - تبويب **Settings ← Authorized domains ← Add domain** وأضف واحدًا تلو الآخر:
     `chinese.albushra.app` · `korean.albushra.app` · `japanese.albushra.app` · `aladeen35.github.io`
3. **Build ← Firestore Database ← Create database** ← المنطقة `eur3 (europe-west)` ← **Start in production mode** ← **Create**.
4. تبويب **Rules**: احذف كل ما فيه، والصق محتوى الملف `academies/firestore.rules` من GitHub، ثم **Publish**.
5. **Build ← AI Logic ← Get started** ← **Gemini Developer API** ← **Enable** (مجاني ضمن حدود يومية، ولا يوجد مفتاح سري في الموقع).
6. ⚙️ **Project settings ← General ← Your apps ← أيقونة الويب `</>`** ← الاسم `academies-web` ← **Register app** ← انسخ كائن `firebaseConfig`.
7. أرسل لي كائن الإعدادات في المحادثة (ليس سرًّا، يظهر في أي موقع يستخدم Firebase) وسأضعه في الكود وأحدّث نسخ الأكاديميات.
8. افتح الأكاديمية ← **ملفي** ← سجّل الدخول بحساب Google ← افتح الرابط `#/admin` ← اضغط **تفعيل حسابي كمدير أول** (مرة واحدة فقط لأول مستخدم).

> **حساب واحد للجميع:** المتعلّم يسجّل مرة واحدة، ثم يدخل كل أكاديمية بالحساب نفسه (ضغطة واحدة على Google في كل نطاق لأول مرة). تقدّم كل لغة مستقل تمامًا.

## ٤) إدارة المحتوى (من التطبيق، بعد الخطوة ٣)
- **الإدارة ← ملفات المحتوى**: افتح أي ملف (مفردات فئة، القواعد، المحادثات، المنهج)، عدّل، ثم **انشر التعديل**. يظهر للمتعلّمين فورًا، و**ارجع للأصل** يلغيه.
- **الإدارة ← طابور الفيديو**: طلبات فيديو النطق من المتعلّمين. بعد إنتاج الفيديو (مثلًا رفعه على قناة يوتيوب) الصق الرابط واضغط **اعتماد**؛ يُعاد استخدامه لكل المتعلّمين.
- **الإدارة ← المتعلّمون**: عدد المتعلّمين والدروس والنقاط في هذه الأكاديمية.
- **الإدارة ← الفريق**: أضف محررًا لأكاديمية واحدة بمعرّف المستخدم (UID) الظاهر في Firebase ← Authentication ← Users. صلاحية كل أكاديمية مستقلة.

## ٥) الأصوات على الهاتف
النطق من محرّك الصوت في الجهاز. على أندرويد: **الإعدادات ← الإدارة العامة ← تحويل النص إلى كلام ← محرّك Google ← الإعدادات ← تثبيت بيانات الصوت ← الصينية (البر الرئيسي)**. بعض الأجهزة تقدّم أكثر من صوت (ذكر/أنثى) فتظهر في قائمة «الصوت» داخل الاستوديو.

## ٦) ما يحتاج خطة Blaze (لاحقًا، بموافقتك فقط)
| الميزة | لماذا تحتاج Blaze |
|---|---|
| أصوات سحابية عالية الجودة بعدة متحدثين (Google Cloud TTS) | تُستدعى من Cloud Functions حتى لا يظهر أي مفتاح في الموقع، وتُخزَّن الملفات في Storage لإعادة استخدامها |
| توليد فيديو النطق آليًا (طابور في الخلفية) | Cloud Function تستقبل الطلبات من `ac_media` وتستدعي مزوّد فيديو بالذكاء الاصطناعي، ثم تضعه «بانتظار المراجعة» |
| رفع ملفات الفيديو والصوت مباشرة | Firebase Storage |
| اشتراكات وخطط مدفوعة، تتبّع تكلفة الـ API | Cloud Functions |
حتى ذلك الحين: الصوت يعمل فورًا، والفيديو يُعتمد يدويًا برابط يوتيوب.

## ٧) مراجعات يقوم بها إنسان
- المحتوى (١٩١ كلمة، ١٢ درس قواعد، ١٠ محادثات، قواعد البينيين، ٤٠ حرفًا) كُتب أصليًا ومرّ بفحص آلي للبينيين والنغمات. يُنصح بمراجعة متحدث صيني لمستويات HSK لبعض الكلمات (مثل 半 و宾馆) ولأسلوب الجمل.
- الشهادات «شهادة إتمام من البشرى» وليست شهادة HSK رسمية، وهذا مكتوب عليها.
